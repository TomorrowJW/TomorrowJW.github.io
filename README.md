# Jiesheng Wu personal homepage

This is a static, bilingual academic homepage designed for GitHub Pages.

## Pages

- `index.html` — Home / 首页
- `research.html` — Research / 研究
- `publications.html` — Publications / 论文
- `students.html` — Students and achievements / 学生与成果
- `recruitment.html` — Recruitment / 招生

The language switch is implemented in `assets/site.js` and remembers the visitor's last choice. Shared visual styles are in `assets/site.css`.

## Deploy to GitHub Pages

1. Upload all files and folders in this directory to the root of the `TomorrowJW.github.io` repository.
2. In the repository settings, open **Pages** and select deployment from the `main` branch root.
3. After GitHub finishes building, visit `https://TomorrowJW.github.io/`.

请将本目录下的全部文件和文件夹上传到 `TomorrowJW.github.io` 仓库根目录，并在仓库 **Settings → Pages** 中选择从 `main` 分支根目录部署。
